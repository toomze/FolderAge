# FolderAge — по виду папки понятно, сколько ей лет и когда её трогали

Живёт в строке меню macOS. Папки на рабочем столе:
- **стареют** по дате создания: синий выгорает, бумага желтеет, появляются заломы и рваные края;
- **зарастают** по давности изменений: пыль → одна группа травы → две группы и паутина → мох по всему низу → заросли с грибами и пауком.

Положили или удалили файл — папка снова чистая. Ещё можно «обновить» вручную — папка снова свежая и чистая.

**Скачать:** [FolderAge.dmg](https://github.com/toomze/FolderAge/releases/latest/download/FolderAge.dmg) — всегда последняя версия.

Меню: **Настройки…**, **Обновить программу…**, **Выход** (по желанию ещё «Протереть все папки»).

## Сборка (на Mac, 1 минута)

```bash
xcode-select --install        # один раз, если нет Xcode
chmod +x build.sh
./build.sh
open build/FolderAge.app
```

Готовые файлы: `build/FolderAge.app` и `build/FolderAge-1.0.0.dmg`.

При первом запуске macOS спросит доступ к папке «Рабочий стол» — разрешите.

## Сборка через GitHub (без Mac под рукой)

1. Создайте репозиторий и запушьте эту папку.
2. Actions → **Build FolderAge** → Run workflow. DMG появится в артефактах запуска.
3. Новая версия: Releases → **Draft a new release** → тег `v1.0.1` → **Publish release**. Через ~2 минуты workflow соберёт `FolderAge-1.0.1.dmg` и `appcast.xml` и прикрепит их к релизу. Текст релиза станет описанием обновления.

## Автообновление (Sparkle)

«Обновить программу…» в меню — проверка, загрузка, установка и перезапуск через [Sparkle](https://sparkle-project.org). Раз в неделю проверка идёт сама (выключается в настройках).

- Лента обновлений: `https://github.com/toomze/FolderAge/releases/latest/download/appcast.xml`.
- Каждый DMG подписывается ключом Ed25519. Публичный ключ — `SUPublicEDKey` в `Info.plist`, приватный — секрет репозитория `SPARKLE_PRIVATE_KEY` (Settings → Secrets and variables → Actions).
- **Приватный ключ храните в надёжном месте.** Если его потерять, уже установленные копии не смогут обновиться автоматически — придётся один раз переустановить вручную с новым ключом.

## Что поменять под себя

`Sources/FolderAge/AppConfig.swift`:
- `telegramURL`, `telegramLabel` — ссылка на фидбек внизу настроек;
- `githubRepo` — `"owner/repo"` для проверки обновлений;
- `Stages` — сроки стадий в днях.

`Resources/Info.plist` — `CFBundleIdentifier` (`com.toomze.folderage`).

## Подпись Developer ID и нотаризация

Чтобы скачанное приложение открывалось без «Всё равно открыть», сборка подписывается сертификатом Developer ID и проходит нотаризацию Apple. Включается секретами репозитория (Settings → Secrets and variables → Actions):

| Секрет | Что это |
|---|---|
| `MACOS_CERT_P12` | сертификат «Developer ID Application» с ключом, `.p12` в base64 (`base64 -i cert.p12 \| pbcopy`) |
| `MACOS_CERT_PASSWORD` | пароль, заданный при экспорте `.p12` |
| `APPLE_ID` | e-mail Apple ID аккаунта разработчика |
| `APPLE_TEAM_ID` | Team ID (developer.apple.com → Account → Membership) |
| `APPLE_APP_PASSWORD` | пароль приложения для Apple ID (account.apple.com → Вход и безопасность → Пароли приложений) |

Без этих секретов сборка подписывается ad-hoc, как раньше. Локально: `SIGN_IDENTITY=… APPLE_ID=… APPLE_TEAM_ID=… APPLE_APP_PASSWORD=… ./build.sh`.

## Как это работает

- Иконка ставится стандартным `NSWorkspace.setIcon` — так же, как при вставке картинки в «Свойства» папки. «Вернуть обычные иконки» снимает их.
- **Старение = сколько в папке ничего не меняли.** Изменение — самая свежая дата изменения/добавления файлов внутри (до 3 уровней вложенности), изменение списка файлов (ловит удаления и переименования), создание или перенос самой папки сюда и её переименование (папку узнаём по номеру файла, поэтому история и настройки переезжают вместе с ней). Наша собственная иконка (`Icon\r`) не считается. Папки с нашей иконкой помечаются атрибутом `com.toomze.folderage`; если папку унесли из отслеживаемого места, ей возвращается обычная иконка. Дата создания папки больше не влияет.
- **Украшения** (трава, мох, грибы / роботы, графики, окна ошибок, провода / водоросли и сундук) — только накладываются поверх папки, саму папку меняет лишь шкала старения — случайные: уровень 0…4 и вариант A/B/C выбираются для каждой папки заново раз в сутки, чтобы папки одной темы выглядели по-разному. Включаются переключателем «Случайные украшения»; при каждом включении выбираются заново для всех папок.
- Папки со своей иконкой не трогаются (настраивается).
- Состояние хранится в `~/Library/Application Support/FolderAge/folders.json`.

Иконки: `Resources/Icons/<тема>/aXnY[V].png` — тема `nature` / `digital` / `ocean`, X — сколько не меняли, 0…3 (до 2 нед. · 2 нед.–1 мес. · 1–3 мес. · больше 3 мес.), Y — уровень украшения 0…4, V — вариант A/B/C. Полоса внизу окна настроек: `Resources/Decor/<тема>_strip.png`.

Темы выбираются в настройках. Стадии старения:
- **Nature** — новая жёлтая бумага → потёртая, загнутый угол → темнее, в скотче → рваная, вся в скотче; украшения — трава, мох и грибы.
- **Digital** — чёткая → ЭЛТ-монитор с крупными пикселями → фиолетовый глитч → тёмный сине-фиолетовый текстовый режим; украшения — пиксельные роботы и жуки, графики, окна ошибок, провода.
- **Ocean** — морское стекло → соль → ракушечник → ржавое железо; украшения — водоросли, кораллы, ракушки, сундук.
